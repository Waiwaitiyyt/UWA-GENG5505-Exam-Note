# UWA-GENG5505-Exam-Note
A comprehensive exam questions note for UWA unit GENG5505 Project Management and Engineering Practice

## English Description

This is a comprehensive repository for the GENG5505 unit in the University of Western Australia, specilised for the final exam of this unit. The detail description is presented below.

### File Details
- **5505.docx** The legecy question bank for final exams. It was concise, but with many typo and out-of-date mistake inside.
- **5505_corrected.md** Updated version of the original question bank for exam, with adaptation based on the 2026 semester 1 lecture slides. This version is recommended to be used for exam preparation
- **5505_corrected.pdf** The pdf version, suitable for printing
- **5505_flashcards.html** A web based quizing flashcard, can be used for testing the knowledge and revision.
- **QnA.md** Some questions in the exam
- **QnA.pdf** Same, good for printing
